PER Scorer · Student walkthrough

Scoring one bee, start to finish

Add the bee, open the video, label what the bee does with start and stop key presses, then read and save the result.

Recap

Every bee, every time

  1. Add the bee: ID, holder, group
  2. Open its video and set fps
  3. Space to play; slow down near a response
  4. Behavior key once to start, again to stop
  5. Check the event log; Z undoes
  6. Read the PER summary; N for the next bee
  7. Save project before you close the browser

About the bee

The bee in this demo is an animation, drawn so each behavior is easy to see. Real recordings are subtler: slow down and step frame by frame whenever you are unsure.
